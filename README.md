# قاعتي · Qaati

نظام إدارة قاعات الأفراح والمناسبات (B2B SaaS) لأصحاب القاعات المستقلين في البحرين والخليج.
واجهة عربية RTL بالكامل، مبنية للجوال أولاً، مع خيار إنجليزي (LTR).

---

## الحالة — MVP مكتمل (المراحل صفر · ١ · ٢ · ٣) ✅

| ✅ منجز                                                                          |
| -------------------------------------------------------------------------------- |
| بنية المشروع + قاعدة بيانات كاملة (١٩ جدول) + ٣٩ اختبار + ٣٢ مساراً              |
| تسجيل ذاتي + دخول + جلسات + اشتراك/تجربة ١٤ يوم/paywall + تفعيل يدوي             |
| تقويم شهري + فلتر قاعة + إنشاء/تعديل الحجوزات + منع تعارض (فهرس DB + فحص تطبيقي) |
| حالات الحجز + انتقالات محكومة + قائمة انتظار + مطابقة تلقائية عند الإلغاء        |
| إدارة القاعات + الفريق (صلاحيات) + بيانات المنشأة + دليل الموردين                |
| العملاء: قائمة + بحث + ملف (سجل حجوزات + سجل تواصل + وسوم)                       |
| العقود: توليد + تعديل الشروط + توقيع + طباعة A4 RTL                              |
| الدفعات على مراحل: قوالب + تسجيل دفعات + حالة تلقائية + تذكير واتساب             |
| فواتير ضريبية بحرينية ثنائية اللغة (ترقيم تسلسلي + بنود + طباعة)                 |
| تذكيرات واتساب (تأكيد/دفعة/يوم المناسبة) + تسجيل كل إرسال                        |
| الموردون لكل مناسبة (فئة + حالة + تكلفة + واتساب)                                |
| لوحة تحكم: حجوزات/متأخرات/محصّل مقابل متوقّع + نسبة التحصيل                      |

**اللغة الإنجليزية:** مبدّل اللغة في الإعدادات، والبنية ثنائية الاتجاه كاملة. مترجَمة فعلياً:
الصفحات العامة + التنقّل + لوحة التحكم + التقويم + قوائم الحجوزات/العملاء + التذكيرات + هَب
الإعدادات. باقي شاشات الإدارة الداخلية نصوصها عربية inline (الترجمات جاهزة في `messages/en.json`،
يبقى ربطها).

**متبقٍ (صقل، خارج نطاق الـ MVP):**

- إكمال ربط `t()` في شاشات الإدارة الداخلية المتبقية.
- ربط بوابة دفع حقيقية (Stripe/Tap/BenefitPay) — الواجهات جاهزة.
- WhatsApp Business API بدل روابط wa.me — الطبقة جاهزة.
- PDF على الخادم بدل صفحات الطباعة.

## التشغيل المحلي

### 1) تثبيت الحزم

```bash
npm install
```

### 2) إعداد ملف البيئة

```bash
cp .env.example .env
```

ثم عبّئ `.env`. ولّد مفتاح المصادقة بـ:

```bash
openssl rand -base64 32
```

**خيار أ — Neon (موصى به):** أنشئ مشروعاً مجانياً على neon.tech، ثم من صفحة المشروع
`Connect` انسخ `Pooled connection` إلى `DATABASE_URL` و `Direct connection` إلى `DIRECT_URL`.

**خيار ب — قاعدة محلية بدون تثبيت:** في نافذة طرفية منفصلة:

```bash
npm run db:local
```

اتركها مفتوحة، وضع في `.env`:

```
DATABASE_URL="postgresql://qaati:qaati@localhost:54329/qaati"
DIRECT_URL="postgresql://qaati:qaati@localhost:54329/qaati"
```

### 3) تهيئة قاعدة البيانات + بيانات العرض

```bash
npm run db:migrate
npm run db:seed
```

### 4) التشغيل

```bash
npm run dev
```

افتح <http://localhost:3000> — للتجربة على الجوال استخدم وضع الأجهزة في DevTools، أو
افتح عنوان الشبكة الظاهر في الطرفية من جوالك على نفس الواي‑فاي.

## بيانات الدخول التجريبية (بعد `db:seed`)

| الدور                | البريد             | كلمة المرور |
| -------------------- | ------------------ | ----------- |
| مالك (ADMIN)         | `admin@qaati.test` | `qaati1234` |
| موظف استقبال (STAFF) | `staff@qaati.test` | `qaati1234` |

المنشأة التجريبية «قاعة النخيل» تأتي بفترة تجربة (‏٩ أيام) و٣ قاعات و٧ حجوزات نموذجية.
أو أنشئ حساباً جديداً من `/signup` لتجربة مسار التسجيل + التجربة المجانية.

### لوحة المشغّل (لإدارة المشتركين)

مسار منفصل تماماً على **`/platform`** — لك أنت كمشغّل المنصّة، لإدارة اشتراكات القاعات
(تفعيل، تمديد، إنهاء) بدل سكربت `billing:activate`. الدخول عبر متغيّري بيئة في `.env`:

```
PLATFORM_ADMIN_EMAIL="you@example.com"
PLATFORM_ADMIN_PASSWORD="كلمة-مرور-قوية"
```

يعرض: كل المنشآت + مالكها + حالة الاشتراك + الإحصائيات، وصفحة تفصيلية لكل منشأة
(المستخدمون، سجل الاشتراك، إجراءات التفعيل/التمديد/الإنهاء).

### قرارات مقصودة

- **العملة بالفلس:** كل المبالغ أعداد صحيحة بالفلس (١ د.ب = ١٠٠٠ فلس). لا أعداد عائمة.
- **الأرقام لاتينية** في الواجهة العربية (أوضح للمبالغ والتواريخ ويتفادى التباس «٠»).
  للرجوع لأرقام عربية-هندية: عدّل `numberLocale` في `src/lib/format.ts` و `formatMoney` في `src/lib/money.ts`.
- **طبقات قابلة للتوسعة:** `BillingProvider` (اليوم يدوي، لاحقاً Stripe/Tap)،
  `PaymentProvider` (لاحقاً BenefitPay)، قناة الإشعارات (لاحقاً WhatsApp Business API).
- **منع تعارض الحجوزات:** فهرس فريد جزئي في قاعدة البيانات على
  `(hall_id, event_date)` للحالات النشطة (HOLD/CONFIRMED) + فحص في منطق التطبيق.
